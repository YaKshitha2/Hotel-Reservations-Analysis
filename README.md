# Hotel Reservations Analysis

## Project Overview

This project analyzes hotel reservation data using SQL to understand booking patterns, guest behavior, hotel performance, and stay-related issues.

## Business Objective

The main objective is to analyze hotel reservation data and provide useful insights to improve hotel operations, customer experience, and booking performance.

## Dataset

The project contains the following datasets:

- Guests
- Hotels
- Rooms
- Bookings
- Stays

## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL
- GitHub

## Key Analysis

- Analyze hotel bookings
- Understand guest patterns
- Analyze room and hotel performance
- Identify cancellations and no-shows
- Analyze stay status
- Identify booking and stay problems
- Analyze service requests
- Generate business insights

## Database Tables

The database contains the following tables:

1. `guests`
2. `hotels`
3. `rooms`
4. `bookings`
5. `stays`

## Project Outcome

The analysis helps identify important booking trends, operational problems, and opportunities to improve hotel services and customer satisfaction.
